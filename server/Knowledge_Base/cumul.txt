# Cumulative Returns - Complete Analysis Guide

## What are Cumulative Returns?
Cumulative returns measure the total return of an investment over a specific period, including all gains and losses. It shows the overall performance of an investment from the beginning to the end of the period.

## Calculation Methods

### Simple Cumulative Return
- **Formula**: (Ending Value - Beginning Value) / Beginning Value
- **Example**: If you invest $1000 and it becomes $1200, cumulative return = ($1200 - $1000) / $1000 = 20%
- **Use**: Quick calculation for single period
- **Limitation**: Doesn't account for multiple periods

### Compound Cumulative Return
- **Formula**: (1 + R1) × (1 + R2) × ... × (1 + Rn) - 1
- **Where**: R1, R2, ..., Rn are individual period returns
- **Example**: 10% return in year 1, 15% in year 2 = (1.10 × 1.15) - 1 = 26.5%
- **Use**: Accurate calculation for multiple periods
- **Benefit**: Accounts for compounding effect

### Logarithmic Cumulative Return
- **Formula**: ln(Ending Value / Beginning Value)
- **Example**: ln($1200 / $1000) = ln(1.2) = 0.1823 or 18.23%
- **Use**: Continuous compounding calculations
- **Benefit**: Easier to work with mathematically

## Types of Cumulative Returns

### Price Return
- **Definition**: Return from price changes only
- **Calculation**: (End Price - Start Price) / Start Price
- **Use**: Pure price movement analysis
- **Limitation**: Ignores dividends and other income

### Total Return
- **Definition**: Return including all income
- **Includes**: Price changes + dividends + interest + capital gains
- **Calculation**: (End Value - Start Value) / Start Value
- **Use**: Complete performance measurement
- **Benefit**: Most accurate measure of investment performance

### Excess Return
- **Definition**: Return above benchmark
- **Calculation**: Investment Return - Benchmark Return
- **Use**: Performance relative to market
- **Benefit**: Shows value added by investment

## Key Metrics

### Annualized Return
- **Formula**: (1 + Cumulative Return)^(1/n) - 1
- **Where**: n = number of years
- **Example**: 50% return over 3 years = (1.50)^(1/3) - 1 = 14.47% annually
- **Use**: Compare returns over different periods
- **Benefit**: Standardized comparison

### Compound Annual Growth Rate (CAGR)
- **Formula**: (Ending Value / Beginning Value)^(1/n) - 1
- **Where**: n = number of years
- **Example**: $1000 to $2000 over 5 years = (2000/1000)^(1/5) - 1 = 14.87%
- **Use**: Long-term performance measurement
- **Benefit**: Smooths out volatility

### Risk-Adjusted Returns
- **Sharpe Ratio**: (Return - Risk-free Rate) / Standard Deviation
- **Sortino Ratio**: (Return - Risk-free Rate) / Downside Deviation
- **Calmar Ratio**: Annual Return / Maximum Drawdown
- **Use**: Compare risk-adjusted performance

## Common Mistakes

### Ignoring Risk
- **Mistake**: Focus only on returns
- **Reality**: Risk matters as much as return
- **Solution**: Consider risk-adjusted returns

### Short-term Focus
- **Mistake**: Focus on short-term performance
- **Reality**: Long-term performance matters more
- **Solution**: Use longer time horizons

### Survivorship Bias
- **Mistake**: Only look at surviving investments
- **Reality**: Failed investments matter too
- **Solution**: Include all investments in analysis

### Over-optimization
- **Mistake**: Over-fit to historical data
- **Reality**: Past performance doesn't guarantee future
- **Solution**: Use out-of-sample testing

## Advanced Analysis

### Rolling Returns
- **Definition**: Returns over rolling windows
- **Use**: Analyze performance consistency
- **Example**: 3-year rolling returns
- **Benefit**: Shows performance stability

### Monte Carlo Simulation
- **Definition**: Simulate future returns
- **Use**: Project future performance
- **Method**: Random sampling from historical data
- **Benefit**: Provides probability distributions

### Factor Analysis
- **Definition**: Decompose returns into factors
- **Factors**: Market, size, value, momentum
- **Use**: Understand return drivers
- **Benefit**: Better risk management
